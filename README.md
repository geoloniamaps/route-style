# route-style

経路表示に適した地図スタイル (Map style optimized for route/navigation display)

道路を控えめなグレー系で表示し、オーバーレイされる経路ラインが明確に目立つようデザインされたスタイルです。

## プレビュー

https://geoloniamaps.github.io/route-style/

## 使い方

```
https://geoloniamaps.github.io/route-style/style.json
```

## 開発

```bash
npm install
npm start
```

## ビルド

```bash
npm run build
```

`docs/style.json` が生成されます。GitHub Pages で配信されます。
